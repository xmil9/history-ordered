# Sequence

Sequence is a phone game about putting history back in order. Choose an archive, arrange a shuffled list of real events, and check how many landed in the right place.

Three archives are on the shelf:

- Battles of Alexander the Great, one round of eight engagements
- Scientific discoveries of the 18th century, two rounds of eight
- US states joining the Union, all fifty states in seven rounds

Dates stay hidden until you check. A best run is saved on the device after every round in an archive has been checked. The latest check of each round is the one that counts. There is no account and no network.

Hold a card and drag it, or use the arrows beside it. On the web preview, the arrows are the sure way to reorder a row.

## Run it locally

```bash
npm install
npx expo start
```

Open the project in Expo Go, a simulator, or the web preview from the dev server.
